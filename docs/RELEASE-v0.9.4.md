The first public release of **SonyTranslator**, a Discord translation plugin for Vencord by **SonyDev**.

Read and send messages in your chosen languages, with styles from Clean to Heavy or a Mirror mode that follows the original. SonyTranslator understands common chat expressions, keeps names and Discord formatting intact, and translates reply previews.

The interface automatically follows your Discord language. English, German, Russian, Ukrainian, Spanish, French, Brazilian Portuguese, Polish, Japanese, Korean, Simplified Chinese and Traditional Chinese are included. Other interface languages use English.

Download **SonyTranslator-AutoInstaller-0.9.4.zip**, extract it fully, and run **Install SonyTranslator.cmd**. The source archive is included for manual installation.
