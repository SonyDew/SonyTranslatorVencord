**SonyTranslator** is a Discord translation plugin for Vencord by **SonyDev**.

Read and send messages in your chosen languages, with styles from Clean to Heavy or Mirror. The interface follows Discord's language and includes twelve language profiles.

Messages already written in your Russian or Ukrainian reading language stay as the author wrote them. English words inside those messages are kept by default, with an option to translate them. Fully English messages still translate normally.

Download **SonyTranslator-AutoInstaller-0.9.5.zip**, extract the whole archive, and run **Install SonyTranslator.cmd** or **Update SonyTranslator.cmd**. The source archive is also included.
