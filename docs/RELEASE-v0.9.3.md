The first public release of **SonyTranslator**, a Discord translation plugin for Vencord by **SonyDev**.

Translate incoming and outgoing messages with Google Translate, with chat styles ranging from Clean to Heavy and a Mirror mode that follows the original message. Supports 12 language profiles, protects participant names and Discord formatting, and translates reply previews.

Download **SonyTranslator-AutoInstaller-0.9.3.zip**, extract the whole archive, and run **Install SonyTranslator.cmd**. The source archive is included for manual installation.
