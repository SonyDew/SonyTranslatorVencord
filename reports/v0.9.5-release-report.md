# SonyTranslator v0.9.5 verification

Confirmed regressions were reproduced with the existing Google transport:
auto source detection interpreted Russian `ладно` as Macedonian, and `спатт` / `а да`
as Serbian. Explicit Russian source avoided those false translations.

The plugin now uses its detected source language when available and restores transport
settings immediately after the provider captures them. Unknown languages still use auto.
Incoming Russian/Ukrainian text already in the reading language stays byte-for-byte intact.
English insertions in that text are preserved by default; disabling the new setting
translates only foreign spans, leaving surrounding target-language text unchanged.
Fully English messages continue to translate normally.

A short Latin-script message cannot inherit Russian/Ukrainian/CJK language from nearby
messages. Dataset rules understand `key assigment` and context-dependent keyboard control
assignment, plus `remap buttons/keys`. Unrelated assignment contexts do not use the shortcut.
Protected names, Discord syntax, emoji, URLs and code are excluded from span translation.

Validation:

- 184 tests and strict core TypeScript: passed.
- Dataset JSON/TypeScript bridge integrity: passed.
- Full Vencord testTsc and production build on `16ec4ea8`: passed.
- Supplied conversation regressions covered in all five style modes.
- Preserving English and translating English spans tested independently.
