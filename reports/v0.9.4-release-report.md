# SonyTranslator v0.9.4 verification

UI localization follows Discord's LocaleStore through a reactive store subscription.
Settings, help text, mode descriptions, the composer tooltip, translation label,
notifications and language-picker names follow the selected Discord locale.
Translation targets and saved settings are unaffected by UI locale changes.

Complete UI packs: English, German, Russian, Ukrainian, Spanish, French,
Brazilian Portuguese, Polish, Japanese, Korean, Simplified Chinese and Traditional Chinese.
Other Discord locales fall back to English. Intl.DisplayNames supplies language names
with a safe fallback for unsupported codes.

Validation on Vencord `16ec4ea8`:

- 168 tests, strict core TypeScript and dataset bridge integrity: passed.
- Full Vencord testTsc and production build: passed.
- Locale coverage, regional aliases, fallback and locale-dependent labels: passed.
- Live language switching in the Discord client was not automated.
